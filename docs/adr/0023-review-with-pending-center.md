# ADR 0023：審核判斷以「待審的中心」為準＋自動補審

狀態：已採用（2026-11-13）。

## 問題
會員先把中心填「無」（有效值）再改成「新竹」（待審），同一次儲存又改了獎銜：獎銜判斷「有沒有中心」時看的是有效值「無」，所以認定沒有中心、**免審直接生效**，並把前一則待審的獎銜申請標為取代。結果只有中心在等審核，獎銜沒有。

## 修正
- 判斷是否有中心時，**待審的值優先於有效值**（會員目前的意圖）。有中心且系統是寰宇，中心與獎銜一起送同一個中心的審核員。
- 補審工作（`src/jobs/requeue.ts`，每 5 分鐘與排程一起跑，可重複執行）：找出已經是這種狀態的資料（寰宇＋真實中心，但獎銜或中心以「免審」存著且未審核），經過正常的寫入流程重新送審並通知該中心審核員；值在核准前不生效。
- 測試涵蓋：同次儲存中心與獎銜一起審、已壞掉的資料被補審、補審可重複執行。
