# ADR 0035：串接指令放公開網址，交接只貼短指令

日期：2026-11-22　狀態：採用（杜杜龍提議：指令太長手機貼不完，改放雲端讓 AI 自己讀）

## 背景
整份串接指令很長，杜杜龍在手機複製貼上到 AI 對話時被截斷，每次交接都要手動選取一大段文字。

## 決定
- 新增公開網址 `GET /handoff/<app_id>`：純文字（`text/plain`）、不需登入、快取 60 秒；內容與後台「給開發 AI 的串接指令」完全相同。不在 `/v1` 底下，不屬於 API 契約。
- 內容本來就只有公開值（App 名稱、網址、scope 清單、規範文字；程式庫是公開的），不含金鑰；**不得**在指令文字裡放任何機密。測試檢查不得出現 `client_secret` 值。未登記的 App 回 404。
- 後台「給開發 AI 的串接指令」頁最上方新增「複製這幾行」：只有網址加兩句話，約 100 字。管理 API 回應多 `url` 與 `pointer_text`。
- 指令第一行之後寫明最新版永遠在該網址，更新時重新讀取。升版 `2026-11-22.3`。
- 原本 `GET /v1/apps/{app_id}/handoff`（App 超級管理員登入後讀取並回報採用版本）不變。

## 後果
- AI 必須能連到 `id.hglobal1985.com`；讀不到時指令要求 AI 回報、不要憑記憶做，杜杜龍改用後台的完整複製鈕或下載。
- 不新增資料表。
