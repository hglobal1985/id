# ADR 0009：匯入 77 位舊會員

狀態：**已廢止**（2026-11-10，業主決定；原於 PR 9 採用）

## 廢止決定（2026-11-10）
- H-Global1985 中央會員系統是全新的系統：除了業主的超級管理員帳號，不放任何舊會員資料。
- 舊網站（回聲的資料庫 `echoes_db`）的 77 位會員不匯入本系統；是否匯入 starry.phd 中央會員系統，在 `starry-phd/id` 另行規劃。
- 匯入程式（`scripts/import-legacy.mjs`、`src/import/legacy.ts` 與其測試）已移除。
- 獎銜階梯原本由匯入程式寫入，改由 migration 建立：`0009_rank_options.sql` 先建立 18 級，`0010_rank_ladder_v2.sql` 換成業主更正後的 33 級（見下方）。教育中心、上手白金／鑽石選項不預先建立，由管理員在後台新增。
- 第一位超級管理員：業主以指定的 Google 帳號第一次登入後，用 `scripts/grant-role.mjs` 設定（帳號不寫進公開 repo）。

## 試匯入紀錄（staging）
2026-11-10 曾在 staging 試匯入 73 位（4 位沒有 Google 識別碼略過），確認方向不符後已全部移除：會員、基本資料、編號、Amway 欄位、角色、匯入稽核紀錄，以及由舊資料產生的教育中心與上手選項。業主電腦上的匯出檔與 SQL 檔已刪除。正式環境從未匯入。

## 原決定（保留作紀錄）
- 獎銜階梯：以業主 2026-11-10 更正版為準（低→高）：無、3%、6%、9%、12%、12%初階、15%、15%銅章、18%、21%、銀章、金章、白金、紅寶石、創辦人白金、創辦人紅寶石、藍寶石、創辦人藍寶石、明珠、翡翠、創辦人翡翠、鑽石、創辦人鑽石、執行專才鑽石、創辦人執行專才鑽石、雙鑽石、創辦人雙鑽石、參鑽石、創辦人參鑽石、皇冠、創辦人皇冠、皇冠大使、創辦人皇冠大使。「無」是可選的選項（沒有獎銜），沒填則為空白；原「鑽石級以上」取消。（此項仍有效）
- 其餘匯入規則（對應欄位、略過沒有 Google 識別碼的會員、舊管理員設為超級管理員等）已不適用。
