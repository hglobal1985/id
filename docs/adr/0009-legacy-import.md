# ADR 0009：匯入 77 位舊會員

狀態：已採用（2026-11-10，PR 9）

## 資料來源
舊網站 Worker `echostars` 的 D1 資料庫 `echoes_db`（yukidu 帳號）：`users` 表 77 位、`upline_names` 11 個上手名字（白金、鑽石）。盤點只讀取結構與統計數字。

## 業主決定（2026-11-10）
- 獎銜階梯（低→高）：3%、9%、12%初階、12%、15%、15%銅章、18%、21%、銀章、金章、白金、創辦人白金、紅寶石、創辦人紅寶石、藍寶石、創辦人藍寶石、翡翠、鑽石級以上；「無」＝沒有獎銜。
- 77 位全部屬於寰宇教育體系，視為已審核。
- 沒有 Google 識別碼的會員（4 位）不匯入。
- 舊欄位全部搬：加入原因、留下原因、備註併入「自我介紹」；天賦數字成為唯讀欄位；舊網站管理員設為超級管理員。
- 回聲 app 的資料（上傳權限、貢獻者、播放次數）不放進本系統；舊網站內部計數不搬。

## 對應
姓名→顯示名稱；信箱→聯絡信箱；手機；生日；居住地→鄉鎮市區；座右銘；頭像（https 網址）；註冊日→建立時間；Amway 編號→會員編號（國家 TW，無則隨機配發）；已審核獎銜→獎銜（已審核）；教育中心、推薦人、上手白金／鑽石（名單內→選項，其他→自填）。所有值都用與 API 相同的規則檢查，不合格的值不匯入，只回報數量。

## 執行
`scripts/import-legacy.mjs`：匯出（唯讀）→ 產生 SQL → 先在 staging 套用。正式環境須業主核准，且在會員開始登入前執行。重跑不會產生重複資料。匯出檔與 SQL 檔只留在業主電腦（已列入 .gitignore）。匯入後所有會員仍需重新同意第二版說明，資格才會生效。
