# ADR 0019：網址結構與搜尋引擎同意

日期：2026-11-11　狀態：採用

## 決定
- `/<編號>`：純淨公開頁——無主選單、無頁尾（隱私權政策／完整隱私說明）、無分享與編輯按鈕。
- `/my/<編號>`：本人登入後的頁面（主選單、分享、編輯、預覽公開頁）；他人或未登入無法開啟。
- `/my/edit`、`/my/<編號>/edit`：編輯頁。`/my` 轉址到本人的 `/my/<編號>`。
- 舊的 `/me`、`/me/edit` 不保留（尚未對外公開，業主 2026-11-11 決定）。
- 編輯頁新增勾選「是否同意公開給搜尋引擎？」（`members.search_indexable`，預設 0；migration 0020；`GET/PUT /v1/me/search-indexing`）。未勾選：公開頁 `noindex`；勾選：`index,follow`（夫妻共用頁需雙方都同意）。本人的 `/my` 頁永遠 `noindex`。

## 後果
- 純淨公開頁沒有隱私權連結，由業主決定（2026-11-11）。
- 串接指令中刪除帳號入口改為 `/my/edit`（版本 2026-11-11.6）。

## 追加（頭像）
- 選好圖片後先出現裁切視窗（拖曳、縮放，圓圈內為保留範圍），確認後才上傳；不再自動取中央正方形。
- 基本資料頁頭像旁的系統／中心／獎銜方框寬度依文字，字級固定不縮小（選單內的獎銜框仍自動縮小）。

## 追加（第八輪）
- 九宮格：加總命數三角形畫在最內側；符合「三個數字都有圈」的列／欄／對角線畫藍色「特殊連線」（`LifeChart.lines`），線寬與圈線相同；圖例刪除括號說明並新增特殊連線。九宮格由 table 改為等高 CSS grid 以便疊 SVG 連線。
- 社群連結：圖示下方文字可自訂（`label`，最多 30 字，所有平台皆可輸入），未填顯示平台名稱，過長自動換行；點文字複製連結、點圖示開新分頁。
- 會員編號不再用圓角框，字體與「會員編號」標題一致。

## 追加（第九輪）
- 頭像：D1 的 BLOB 欄位在正式環境回傳「數字陣列」，直接當回應內容會是空的，造成頭像／自訂圖示無法顯示；改用 `blobBytes()` 轉成位元組，測試用 D1 同步改成回傳數字陣列以便抓出同類錯誤。
- 預覽公開頁按鈕固定在最右側，編輯頁與 /my 頁一致。
- 社群連結：圖示下方名稱框固定兩行高，字太多自動縮小；編輯模式點名稱可編輯該連結（`PUT /v1/me/social-links/{id}`：網址與名稱）。
- 九宮格改為單一 SVG、固定幾何：每個數字固定 100x80 的格子，圈數再多也不擠壓；加總命數為實心紅三角形在數字下層，數字白色。
- 勾選文字改為「是否同意讓搜尋引擎為你打知名度？」。
- 每頁底部右側顯示「網站設計 杜杜龍」（純淨公開頁除外）；隱私權政策與完整隱私說明合併為單一文件 `/privacy`（完整說明在 `#full`），`/privacy/amway` 轉址；串接指令 2026-11-11.7。
