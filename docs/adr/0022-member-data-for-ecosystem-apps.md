# ADR 0022：寰宇生態系 App 可使用會員資料（含設為隱藏的）

狀態：已採用。業主 2026-11-13 核准政策文字（含《Amway 會員資料之蒐集與跨系統利用告知》補一句、公開/隱藏說明）並決定行動大學欄位「全部勾選」；政策已上線。業主 2026-11-13 決定：「會員的隱藏開關只管對外；寰宇生態系的 App 使用，不用再經過授權；所有欄位都可以被使用，不排除特殊欄位；包含只在 App 內處理，也包含顯示給生態系內其他會員看。」

## 決定與做法
- **公開／隱藏的意思改為**：只決定「對外公開頁」顯示什麼。對寰宇生態系內經登記的 App，不受這個開關限制。
- **仍然維持的限制（是我的建議，可由業主調整）**：
  1. 預設全部關閉。業主在後台「平台設定」替每款 App 勾選可使用的欄位（可以全選），沒勾的欄位讀不到。
  2. 只能讀「在該 App 登入過」的會員（避免任何 App 能掃全站會員）。
  3. 每次讀取中央都有稽核：App、筆數、欄位**名稱**、用途；不記內容。
  4. App 不得長期保存（只放記憶體或必要的短暫快取）、不寫日誌與分析工具、不轉給生態系以外的人（寫進串接指令與檢查清單）。
  5. 需要審核的 Amway 欄位（獎銜、中心）只回已審核的；非 Amway 會員的 Amway 欄位為空值；對外公開頁（生態系以外的訪客）仍只顯示會員設為公開的欄位。
- **端點**：`POST /v1/apps/{app_id}/members/lookup`（服務 Token）：`{member_ids ≤ 50, fields[], use: "process" | "display"}` → `{members[{member_id, fields{}}], not_found[]}`。`process`＝只在 App 伺服器內處理（統計、對帳、判斷資格…）；`display`＝顯示給生態系內其他會員看。
- **可勾選的欄位**：全部基本資料欄位（含真實姓名、手機、生日…）、全部 Amway 欄位、頭像、會員編號（公開網址代碼）。社群連結不在內（需要時再加）。
- 串接指令 `2026-11-13.1`、檢查清單第 14 項、`docs/integration-guide.md` 6.9 同步。

## 待業主核准的隱私權政策文字（尚未寫進 `privacy-policy.ts`）
> 這是個人資料的使用目的變更，建議上線前請法務或律師看過；既有會員是在舊承諾（「其他欄位由您自己設定是否公開」）下提供資料的。
1. **§5「公開與分享」第一點改寫**：「公開基本資料頁：頭像與會員編號一律公開；其他欄位由您自己設定是否公開。您設定的『公開／隱藏』只決定本網站對外公開頁顯示的內容。」
2. **§5 新增一點**：「寰宇生態系內的 App：您註冊或登入的寰宇生態系 App（由成就寰宇股份有限公司營運或授權，並經本網站登記）為了提供服務、處理報名與付款、顯示會員之間的資訊，可以使用您的基本資料與 Amway 會員資料，包括您設定為『隱藏』的欄位，不需另外取得您的同意。這些 App 只會取得其功能所需的欄位，不得長期保存、不得提供給寰宇生態系以外的人；本網站會留下每次使用的紀錄（哪一款 App、哪些欄位、幾筆，不含內容）。」
3. **§4「使用目的」新增一點**：「在寰宇生態系內的 App 提供服務、處理報名與付款、顯示會員之間的資訊。」
4. **欄位旁「公開／隱藏」按鈕的說明**（短版）：「公開＝任何人都看得到；隱藏＝不在公開頁顯示（寰宇生態系內的服務仍可能使用）。」
5. **站內通知（業主 2026-11-14 決定不發；腳本保留）**：標題「隱私權政策已更新」，內文「我們更新了隱私權政策：您設定為『隱藏』的資料，仍可能被寰宇生態系內經登記的 App 為提供服務而使用，但不會對外公開，也不會提供給生態系以外的人。詳見頁尾的『隱私權政策』。」發送方式：`scripts/notify-policy-update.mjs` 產生 SQL，由業主核准後在 production 執行（寫入正式資料，需業主同意）。
6. 《隱私同意文字（第二版）》是 Amway 與 starry.phd 之間的跨系統資料互通告知，**不是**寰宇生態系內部的規定，這次不改；但 Amway 欄位在寰宇生態系內被其他 App 使用，建議在 `/privacy/amway` 的「利用範圍」加一句，是否要加請業主一併決定。

## 風險（請業主知悉）
- 把原本「會員自己決定」改為「平台決定」，是對會員的重大變更：若有會員不接受而要求刪除或投訴，要有處理流程（現有的刪除帳號可用）。
- 「display」讓生態系內任何 App 都可能顯示別人的手機、生日、真實姓名等敏感欄位；我已把它做成「每款 App、每個欄位逐一勾選」，**建議不要一次全選**，只勾功能需要的。
- 技術上我無法阻止 App 開發者違規保存，只能靠串接指令、稽核紀錄與合約。
