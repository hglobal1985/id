# ADR 0026：頭像改存 R2

日期：2026-11-14。狀態：程式已寫並測試；**部署後要實測**。取代 ADR 0014 中「R2 暫不啟用、頭像存 D1」的部分。

## 業主決定
2026-11-14：「R2 可啟用」「R2 現在做」。

## 決定
- 建立兩個 R2 bucket（新加坡區，與資料庫同區）：`hglobal-id-files`（正式）、`hglobal-id-files-staging`（測試）。帳號內既有的 bucket `learn`（行動大學用）不動。
- **只搬頭像**（單張最大 128 KB、會隨會員增加）。社群圖示每張只有 16～32 KB，留在 D1。
- 做法：圖片位元組放 R2（鍵 `avatars/<會員識別碼>`），D1 的 `member_avatars` 仍留類型與擁有者；`data` 欄位放**空內容**代表「位元組在 R2」。對外網址 `/avatar/<會員識別碼>` 不變，App 與網頁都不用改。
- 沒有綁定 R2（本機測試）或 R2 寫入失敗時，退回舊做法存 D1，上傳不會失敗。
- **舊資料自動搬家**：排程每 5 分鐘把仍在 D1 的頭像搬 20 張進 R2，確認大小相符才把 D1 內容換成空標記；會員剛好換了新圖就不動。讀取時兩種都能服務，搬家期間不中斷。
- **清除**：移除頭像、改用 Google 頭像、刪除帳號時立刻刪 R2 檔案；每日排程再掃一次「沒有主人的檔案」（超過 1 小時才掃，避免誤刪剛上傳的）。
- 隱私：R2 不公開，只能由 Worker 讀取；對外仍經 `/avatar/...`（只回圖片、`nosniff`、沙盒 CSP）。

## 之後
- 若社群圖示、App 圖示也要搬，照 `src/lib/files.ts` 的做法加（記得補孤兒檔掃除）。
