# ADR 0018：第五輪介面調整與「系統」顯示

日期：2026-11-11　狀態：採用

## 決定
- 「系統」（直銷商培訓系統）直接顯示 `寰宇`，不再出現 H-Global1985；migration 0019 將既有值與詞庫轉為「寰宇」。
- 強制公開欄位只剩顯示名稱、國家與衍生資料；Amway 欄位（系統、中心、獎銜、推薦人、上線）可由會員自由隱藏，預設公開（皇冠大使預設隱藏）。公開頁頁首方框隨可見度隱藏。
- 生日與生命靈數合併為單一區塊 `birthday`（移除 `life`）。
- 新增連結網址：未輸入 scheme 一律補 `https://`；只接受 http/https。
- 公開網址旁新增原生分享按鈕（Web Share API，iOS/Android 圖示不同）。
- 名稱強制單行，依長度縮小字級。

## 後果
- 區塊排序鍵 `life` 不再使用；`birthday` 沿用。
