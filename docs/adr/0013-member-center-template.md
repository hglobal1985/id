# ADR 0013：會員中心版面與繁星範本同步

狀態：已採用（2026-11-10）。業主要求寰宇中央會員的介面細節與功能與 starry.phd 中央會員範本一致。

## 決定
- **版面與樣式**：沿用同一套夜空版面——固定在上方的圓角膠囊主選單（頭像／姓名、後台、九點 App 選單、登出）、半透明卡片、可收合區塊（＋／－）、頭像圓章（無照片時顯示姓名縮寫）、統計方塊、燈號。品牌名一律 H-Global1985。樣式全在同網域檔案 `/assets/site.css`；CSP 不允許內嵌樣式，所以尺寸與顏色都用 class（`avatar sm/md/lg`、`lc-ico c0–c7`），測試保證頁面沒有 `style=`。
- **主選單**：登入後顯示頭像／姓名（連到 /me）、有管理角色者顯示「後台」、九點按鈕、登出；未登入顯示品牌列。
- **App 選單頁 `/apps`**：九點按鈕的目的地。公開頁，只列名稱與網頁版網址；暫停中的 App 灰掉並標示「暫停中」，已停用的不顯示。圖示為 App 名稱首字＋依 app_id 固定的顏色。
- **基本資料頁 `/me`**：頁首大頭像＋姓名＋預設會員編號；未讀通知移到最上方；次要區塊（帳號資訊、登入紀錄、資料刪除）改成可收合；底部「下載我的資料」「登出」。
- **登入紀錄**（新）：`GET /v1/me/sessions`、`POST /v1/me/sessions/{id}/revoke`、`POST /v1/me/logout-all`。列出會員網站與各 App 的有效登入（App、裝置、最後使用）；可登出其他登入，不能用這支登出目前的瀏覽器（回 409）；「登出所有裝置」同時結束所有 App 與本瀏覽器。只限會員網站本身（App 回 403），全程留稽核，不回傳任何 token。
- **下載我的資料**（新）：`GET /v1/me/export`，回傳本人資料的 JSON 檔（基本資料、公開設定、會員編號、Amway 欄位、同意紀錄、用過的 App），不含 token 或雜湊；留稽核 `member.export`。
- **後台**：改成滿版加上方列（brand、九點、主選單、「更多」下拉、窄螢幕漢堡選單）；新增第一個分頁「總覽」＝`GET /v1/admin/overview`（任何管理角色皆可）：會員數、近 7 天新會員／登入、App 目前登入數、待審核、待處理刪除申請，以及四個燈號（App 狀態、待審核、刪除申請、App 登記）。燈號規則在 `src/admin/lights.ts` 並有單元測試。
- 登入頁、訊息頁改成同一套夜空樣式。

## 刻意不同於 starry.phd 的地方
- 沒有電池、量子電池、兌換序號、訂閱購買、推薦達人、組織網（寰宇沒有這些功能）。
- 沒有 Apple 登入與通行密鑰（業主暫不做）；登入方式只有 Google。
- 沒有「遠端設定」編輯（業主 2026-11-10 決定移除）。
- 沒有服務條款、客服單、公告與維護橫幅、啟動器圖示上傳：寰宇尚未提供對應文字或功能，需要業主提供內容後再做。
- 頭像上傳仍回 501（R2 不啟用）。
