# ADR 0007：管理角色、合併頁、代調整、稽核

狀態：已採用（2026-11-10，PR 7）

## 決定
- 角色：超級管理員（`super_admin`）、秘書（`secretary`，即寰宇秘書）、審核員（`reviewer`）。管理人員也是會員，用同一個 Google 登入；一人可有多個角色（`staff_roles`）。
- 權限：

| 權限 | 超級管理員 | 秘書 | 審核員 |
|---|---|---|---|
| 審核（核准／駁回）、代調整六欄位、查會員 | ✔ | ✔ | ✔ |
| 維護 Amway 選項清單（獎銜階梯等） | ✔ | ✔ | — |
| 合併頁（上手三欄位） | ✔ | ✔ | — |
| 查稽核紀錄 | ✔ | ✔ | — |
| 設定管理角色 | ✔ | — | — |

- 後台 API 在 `/v1/admin/*`，只接受中央網站的登入 cookie（不接受 app 的 token）；會改資料的請求必須來自本網站（檢查 `Origin`，防跨站請求）。
- 設定角色屬於敏感操作：10 分鐘內必須重新以 Google 登入，否則回 401 `reauth_required`；不能移除最後一位超級管理員。
- 第一位超級管理員由業主用 `scripts/grant-role.mjs` 產生 SQL 自行設定，之後在後台管理。
- 新的審核申請會通知所有管理人員（站內通知）；審核結果通知會員。
- **合併頁**（業主 2026-11-10 確認）：會員在上手欄位選「其他」自行填寫的名稱，管理員可以一次合併到正式選項，並可代調整個別會員的上手三欄位。
- 稽核：所有後台動作都記 `actor_type = staff`；查詢可依對象、操作人、動作篩選。稽核紀錄不含 token、機密、姓名、信箱與 Amway 欄位的值。
