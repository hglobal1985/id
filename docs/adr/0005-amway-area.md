# ADR 0005：Amway 專區、同意、獎銜審核、站內通知

狀態：已採用（2026-11-10，PR 5）

## 決定
- API（串接指令包第 4 節）：`GET /v1/amway/field-definitions`、`GET /v1/amway/consent`、`GET /v1/me/amway`、`PUT /v1/me/amway/enabled`、`PUT /v1/me/amway/fields/{field_key}`；站內通知 `GET /v1/me/notifications`、`POST /v1/me/notifications/{id}/read`。
- 欄位：教育體系、教育中心、獎銜、推薦人、上手皇冠大使／鑽石／白金（`amway_id` 已併入會員編號）。Amway 資料只存在本系統。
- 選項清單存在 `amway_options`，由管理員維護（管理介面在 PR 7）；固定的結構選項只有教育體系 `hglobal`（顯示 H-Global1985）與各「單選＋自填」欄位的「其他」。獎銜的 `sort_order` 就是獎銜階梯（由低到高）。
- 同意：開啟「我是Amway會員」必須帶目前的同意版本（第二版，`"2"`），每次同意都寫入 `consent_records`（版本與時間）；舊版同意視為過期，需要重新同意（`consent_required`）。關閉＝隱藏並暫停資格，資料保留，沒有刪除按鈕。
- 審核：教育體系選 `hglobal` 需審核；教育體系（生效或待審）為 `hglobal` 時獎銜需審核；其他欄位免審、立即生效。待審期間維持舊值；駁回維持舊值（沒有舊值就是無）。教育中心只在教育體系為 `hglobal`（生效或待審）時可填。
- 審核人員可代調整六欄位（教育體系、教育中心、獎銜、上手鑽石／白金／皇冠大使），視為通過、留稽核、通知會員。審核與代調整的服務函式已完成並有測試；管理員角色、權限與後台畫面在 PR 7。
- 夫妻共用獎銜：綁定時取階梯較高者；之後任一方的獎銜變更、審核結果同時套用到兩人；解除後各自保留。撞號候選與配偶資訊只顯示「已審核」的獎銜。
- 站內通知文字不提任何其他系統；夫妻綁定通知附「一鍵解除」動作（`DELETE /v1/me/spouse`）。

## 待業主提供
- 獎銜階梯（含「12%初階」這類分級）、教育體系、教育中心、上手名單的正式清單。
