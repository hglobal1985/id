# ADR 0008：網頁介面、完整隱私說明頁、資料刪除

狀態：已採用（2026-11-10，PR 8）

## 決定
- 中央網站頁面：`/`、`/me`（基本資料）、`/admin`（後台）、`/privacy`（隱私權政策，2026-11-10 業主核准）、`/privacy/amway`（完整隱私說明）、`/<會員編號>`（公開基本資料）、`/logout`。
- 頁面的程式與樣式是同網域檔案（`/assets/*.js`、`/assets/site.css`），CSP 只允許 `script-src 'self'`；畫面一律用 `textContent` 輸出，會員輸入不會被當成 HTML。
- 中央網站自己的頁面以登入 cookie 呼叫同一組 `/v1` API（視為站方本身，`app_id = central`）；會改資料的請求必須來自本網站（`Origin` 檢查）。app 仍只能用 token。
- 「基本資料」頁完全由欄位定義 API 驅動：頭像三操作（上傳與 Google 頭像目前顯示「目前不提供」）、會員編號清單與撞號綁定、各欄位與公開設定、帳號資訊、Amway 專區（勾選→短版同意→欄位與審核狀態）、夫妻綁定、通知（含一鍵解除）、資料刪除。
- 公開基本資料頁：只顯示公開欄位；頭像與會員編號永遠公開；已綁定夫妻共用網址，可切換查看兩人。
- 完整隱私說明：照第二版「三、完整版」第 1～8 節刊登（獨立頁，不併入隱私政策）；文件內部備註不刊登，草稿標記「（新增）」已拿掉。
- 資料刪除：只能在中央網站本人登入後申請（app 不能），需 10 分鐘內重新登入；可在處理前取消；管理員（超級管理員、秘書）15 日內執行，執行也需 10 分鐘內重新登入。
  - 刪除 Amway 資料：移除 Amway 欄位、審核紀錄，關閉「我是Amway會員」，記錄撤回同意。
  - 刪除帳號：移除基本資料、編號、通知、角色，解除夫妻綁定，登出所有裝置，帳號匿名化並標為已刪除；Google 帳號釋出（可重新註冊成新會員）。稽核紀錄保留。資料列的實體刪除需業主另行核准。
